# Modern React & UI Guidelines

1. Use functional components with typed props using TypeScript interfaces.
2. Structure state into local (useState), shared context, or server-cached state.
3. Keep UI accessible: use semantic HTML, clear aria-labels, and high-contrast styling.
4. Avoid bulky external dependencies when standard CSS/Vanilla styling can achieve the result.
5. Provide clean loading, empty, and error states for all asynchronous data flows.
